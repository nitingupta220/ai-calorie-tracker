# Sketch 004 · Onboarding flow

## Design Question
First impression surface. 6 steps: welcome → goal → diet → body+budget → DPDP consents → first meal. Where does Bali land? Form vs chat?

## How to View
`open .planning/sketches/004-onboarding-flow/index.html`

## Variants
- **A · Swipe-stack** — one step per screen. Big cards. Bali narrates intent. Best for clarity + completion-rate.
- **B · Vertical scroll** — long page with sequentially unlocked sections. Sees all 6 steps at a glance. Bali only in step 1.
- **C · Conversational** — Bali IS the onboarding. Chat-style. Highest "wow" but longest path. Auto-condense post-onboarding.

## What to Look For
1. Completion-rate intuition — which gets users to step 6?
2. Where does Bali introduce himself?
3. DPDP consents (step 5, not shown in sketch) — buried or first-class?
4. "Wow moment" placement — onboarding end or first meal log?
