# Sketch Manifest

## Design Direction

**Coach Dark** aesthetic locked from `.planning/research/VISUAL-IDENTITY.md` and Bhog spec HTML. Warm charcoal (`#1A1612`) background with copper-amber (`#C9A26B`) primary accent + ivory text + sage secondary. Inter + IBM Plex Mono. Premium-restrained — adult, not kindergarten. Photo-to-macros hook + inline advice moat invariant: advice ALWAYS rendered inline on macros card, never a separate tab.
