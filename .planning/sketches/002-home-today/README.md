# Sketch 002 · Home / Today

## Design Question
Core surface user opens daily. Locks: macros progress, last 3 meals, streak, water, weight, push-gap. How to compose without HealthifyMe-density?

## How to View
`open .planning/sketches/002-home-today/index.html`

## Variants
- **A · Hub-stack** — vertical hub. Most info-dense. Bali via push only.
- **B · Carousel-hero** — big ring hero + horizontal meal carousel. Most visually striking, screenshot-friendly.
- **C · Minimal-list** — stripped feed with inline Bali card. Retention-optimal — Bali lives in the feed not in pushes alone.

## What to Look For
1. Where does Bali show up? Push-only / hero / inline-in-feed?
2. Screenshot-shareability test: which variant looks best as Insta story?
3. Meal density: 3 meals visible without scroll?
4. Streak/water/weight tile placement?
