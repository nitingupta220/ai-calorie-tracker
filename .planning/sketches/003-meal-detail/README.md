# Sketch 003 · Meal detail

## Design Question
This is the moat surface. Photo + macros + inline advice + edit/correction. The moat dies if advice goes to a separate "Coach" tab. How to expose detail without losing the inline invariant?

## How to View
`open .planning/sketches/003-meal-detail/index.html`

## Variants
- **A · Modal sheet** — bottom sheet over Today. Lightweight return. Best for "log + glance + move on."
- **B · Full page** — photo hero + decomposition chips. Highest information density. Best for inspect/correct workflow.
- **C · Expand-in-place** — tap card → expands in feed. No nav transitions. Lightest. Best for retention — never leave the feed.

## What to Look For
1. Inline-advice invariant honored in all three?
2. Correction-flow surface — how many taps to fix a dish?
3. IFCT decomposition chips visible / hidden / on-tap?
4. Conf-pill placement — confidence-gate UX clear?
