# Sketch 001 · Camera capture

## Design Question
Photo-to-macros is the install hook. How does the capture surface read? Does reference-object guidance feel helpful or fussy? Where does Bali enter — at capture, after result, or both?

## How to View
`open .planning/sketches/001-camera-capture/index.html`

## Variants
- **A · Reticle overlay** — viewfinder + corner markers + center reticle + ₹-coin reference hint. Explicit framing aid. Best for thali multi-item where confidence-gate UX matters.
- **B · Minimal-tap** — viewfinder + giant shutter. Zero UI chrome. Fastest-to-first-shot. Bali speaks AFTER, on the result card.
- **C · Coach-narrated** — Bali speech bubble narrates first-time. Mascot becomes UX, not decoration. Trade-off: chatty on shot #50.

## What to Look For
1. Does the reference-object hint feel helpful or annoying?
2. Where does Bali land — capture moment or result moment?
3. Bottom controls clutter vs clean?
4. Confidence-gate UX visible in any variant?
