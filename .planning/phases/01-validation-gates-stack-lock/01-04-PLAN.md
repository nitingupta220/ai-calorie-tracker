  <name>Task 1: Founder shoots and weighs 30 meal photos across 3 buckets</name>
  <what-built>Claude has verified dish_decomposition.json (Plan 01). The founder now needs to physically shoot 30 meal photos over 3-5 days while eating real meals — with a kitchen scale in hand for every shot.</what-built>
  <how-to-verify>
    PREREQUISITE — Do not start shooting until the kitchen scale has arrived. Shooting before the scale = Pitfall E-02 (forced to use eyeballed "truth" if you don't re-weigh later).

    SHOOTING PROTOCOL (from CURATION-CHECKLIST.md + gate_0a_vision.md):

    Bucket 1 — SINGLE DISH (10 photos):
    - One dish per plate. Katori of paneer butter masala, a plate of dosa, 2 boiled eggs, etc.
    - Reference object MANDATORY: ₹10 coin OR open palm placed next to dish BEFORE photographing.
    - Weigh: tare the scale with empty vessel → place dish → record weighed_total_g.
    - Variety: aim for pan-Indian (2), North (3), South (2), West/East (2), + 1 off-whitelist.
    - Lighting: at least 3 daylight, 2 indoor warm, 2 dim, 2 fluorescent (not all on the same day).

    Bucket 2 — MIXED (10 photos, 2-3 items per frame):
    - Dal + rice + sabzi, idli + sambar, paratha + curd + pickle, etc.
    - Reference object MANDATORY in every mixed photo.
    - Weigh each component separately using tare-per-vessel method: weigh each katori before plating. Record in component_weights_g JSON: {"dal_tadka":150,"rice":120,"aloo_sabzi":90}.
    - Include at least 1 off-whitelist item (e.g., Hyderabadi biryani, Bengali macher jhol).
    - Lighting variety: same as single.

    Bucket 3 — THALI (10 photos):
    - Full thali: 4-7 items visible. South thali on banana leaf, North steel thali, street thali, etc.
    - Weigh each katori separately (same tare method). Thali is reported-only but still weigh.
    - Reference object: include where natural (coin on rim, palm gesture at side).
    - Off-whitelist quota: at least 1 thali with a regional dish not in the 50-dish whitelist.

    PHOTO STANDARDS:
    - Use the actual Android phone you intend to ship with (Redmi / Samsung A-series / Pixel a).
    - DO NOT stage or food-style. Messy real life: half-eaten OK, spilled ghee OK, hand visible OK.
    - DO NOT use food blog / Instagram / Google Images photos.
    - Shoot in phone's default format (HEIC or JPEG). HEIC must be converted.

    JPEG CONVERSION (after shooting):
    - Resize longest edge to ≤1280px, JPEG quality 0.7, strip EXIF (especially GPS metadata — DPDP PII).
    - Use Pillow: python -c "from PIL import Image; img=Image.open('input.heic'); img.save('output.jpg', 'JPEG', quality=70)" or use any image editor.
    - Verify no GPS in EXIF: python -c "from PIL import Image; from PIL.ExifTags import TAGS; img=Image.open('output.jpg'); exif=img._getexif() or {}; gps=[TAGS.get(k) for k in exif if 'GPS' in str(TAGS.get(k,''))]; print('GPS tags:', gps)"
    - Expected: GPS tags: [] (empty).

    FILENAME CONVENTION:
    - data/photos/single/NN-<dish-shorthand>-<lighting>-<note>.jpg
    - data/photos/mixed/NN-<items>-<lighting>-<note>.jpg
    - data/photos/thali/NN-<region>-<lighting>-<note>.jpg

    LABELS_TRUTH.CSV — fill one row per photo IMMEDIATELY after shooting (not from memory):
    filename,dish_id,weighed_total_g,component_weights_g,has_reference_object,notes
    - dish_id: must exactly match a key in data/dish_decomposition.json, OR "__off_whitelist__:<free-text>" for off-whitelist dishes.
    - weighed_total_g: the scale reading in grams (single-dish or thali total).
    - component_weights_g: JSON string for mixed/thali: {"dal_tadka":150,"rice":120}. Leave blank for single.
    - has_reference_object: true or false (must be true for all single + mixed).
    - notes: any ambiguity for the labeling pass.

    Diversity hard requirements (fail if not met):
    - ≥6 cuisines represented: North, South, West, East, Pan, Maharashtrian street
    - ≥2 non-veg photos (chicken curry, eggs, fish)
    - ≥3 off-whitelist photos across all buckets

    When done: run
    python -c "
    import os, csv
    for bucket in ['single','mixed','thali']:
        jpgs = [f for f in os.listdir(f'data/photos/{bucket}') if f.endswith('.jpg')]
        rows = list(csv.DictReader(open(f'data/photos/{bucket}/labels_truth.csv')))
        print(f'{bucket}: {len(jpgs)} JPGs, {len(rows)} CSV rows')
        missing_weight = [r['filename'] for r in rows if not r.get('weighed_total_g') and not r.get('component_weights_g')]
        if missing_weight: print(f'  WARNING: no weight for: {missing_weight}')
        no_ref = [r['filename'] for r in rows if bucket != 'thali' and r.get('has_reference_object') != 'true']
        if no_ref: print(f'  WARNING: missing reference object: {no_ref}')
    "
    Expected: 10 JPGs + 10 CSV rows per bucket; no missing-weight or missing-reference warnings for single + mixed.

    git add data/photos/ && git commit -m "feat(phase-1): Gate 0a photos — 30 weighed meal photos (10/10/10)"
