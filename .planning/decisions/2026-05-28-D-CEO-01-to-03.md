## D-CEO-01 · WhatsApp share-photo hook via Meta Cloud API direct

- **Status:** LOCKED (acceptance gated on Meta Business Verification per pre-flight checklist)
- **Context:** India lives in WhatsApp. Lowest-friction install funnel. Twilio production requires CC. Meta WhatsApp Cloud API direct provides 1K free conversations/mo with NO credit card (Aadhaar/PAN/GSTIN verification only). Twilio sandbox only for dev fallback.
- **Decision:** Meta WhatsApp Cloud API direct. New `POST /whatsapp/webhook` route. Same `ai_provider.py` + advice engine. Response footer = install CTA. `whatsapp_session` table with 24h TTL (DPDP §5 legitimate-use posture; pre-install lawful basis via inline consent footer). Indian BSP fallback (Interakt / AiSensy UPI-native) pre-onboarded BEFORE public launch.
- **Consequences:** Aggregate 7-10d effort spanning Phase 2 (table + stub) + Phase 4 (wire after verification) + Phase 5 (launch). Privacy policy adds Meta as named cross-border processor (alongside Singapore Render disclosure from D-01). If Meta Verification rejected twice, defer to V1.1 via TODOS-9.

## D-CEO-02 · Social streak ladder = own-rank pill only V1

- **Status:** LOCKED (reduced scope per /plan-ceo-review spec-review concern #17)
- **Context:** Strava-pattern leaderboard data shows +50% D14 retention. But full top-N cohort leaderboard requires anonymized-handle generation, collision policy, cohort-key UX, DPDP minimization — too much for V1 bandwidth.
- **Decision:** V1 = own-rank only ("47th in Mumbai · 7-day streak"). Postgres `streak_event` table + nightly cron at 22:00 UTC (03:30 IST off-peak) computes city-month-cohort percentiles. Opt-in via Settings (default OFF for DPDP minimization). If cohort < 5 opt-ins, pill hides. Top-N cohort leaderboard deferred to V1.1.
- **Consequences:** 3-4d Phase 3 mobile + Phase 2 cron. Compounds with existing streak mechanic without ballooning Phase 3 scope. V1.1 trigger to add top-N if D14 retention metric warrants.
