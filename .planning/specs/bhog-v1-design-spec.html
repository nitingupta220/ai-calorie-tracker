02

Design System · Coach Dark

Dark default. Warm charcoal background. Copper-amber primary accent. Ivory text. Sage secondary. Spacious one-card density. Spring motion + coordinated haptics. Distinct from every direct competitor.

Philosophy

  • Dark default. Light theme V2 only if requested.
  • Spacious, one-card-at-a-time. Persona judges quality by whitespace.
  • Restrained accent. Copper-amber only on intent / focus / CTA.
  • Numerics are mono. Macros + ₹ + dates use IBM Plex Mono tabular figures.
  • Motion = spring. Cubic-bezier reads dated.

Avoid

  • Saffron primary — BJP/Hindutva political signal post-2022.
  • Neon-on-black — peaked 2023.
  • HealthifyMe-green — owned by incumbent.
  • Bridal gold — wrong cultural register.
  • Red as brand — keep for warning state only.
  • Illustrated food — undermines photo-to-macros hook.

AI Decisions

AI-SPEC v1

Full contract: .planning/phases/01-validation-gates-stack-lock/01-AI-SPEC.md (937 lines).

System type

Hybrid · Structured Extraction (vision → dish + portion + macros) + Grounded Content Generation (advice from last-3-day log). NOT RAG. NOT agentic. NOT conversational.

Framework

Direct SDKs + Pydantic v2 behind ai_provider.py. No LangChain / LangGraph / LlamaIndex / CrewAI. Zero framework lock-in.

Pipeline · single API response, <8s P95

POST /meals/photo  (multipart presigned)
   │
[1] presigned PUT → R2 india jurisdiction (mobile direct, no proxy)
[2] FastAPI receives photo_url + user context
[3a] VisionProvider.identify(photo_url)        ── Gemini 2.5 Flash
       returns: { items: [{name, portion_g, conf}] }
[3b] DishDecomposer.macros(items)              ── deterministic
       JSON lookup → IFCT 2017 aggregate
[4]  asyncio.gather(
       persist_meal(macros),
       AdviceProvider.coach(user, last_3d, dish) ── Groq Llama 3.3 70B
                                                    6s hard timeout
     )
[5] rubric_validator.score(advice)             ── 4/4 check
       ├─ 4/4 → render
       ├─ <4/4 → retry once
       └─ fail → per-dish template fallback
[6] MealResponse { macros, advice, advice_version, confidence }

Critical failure modes

Wrong dish / fabricated macros

Stratified Gate 0a · Pydantic validation · two-step pipeline (IFCT lookup, never LLM math) · confidence-gated UI.

Generic advice

Server-side 4/4 rubric validator · retry once · template fallback · WoZ QA Gate (≥35 examples, ≥70% AI-vs-WoZ match) before alpha.

PII to LLM

CI lint bans user.name/phone/dob in advice-prompt path · only de-identified user_id + goal/macros/diet fields.

Vendor lock-in

ai_provider.py 429-fallback · per-call cost log · pre-launch load test · OpenRouter fallback drill before alpha.

Open Risks & Reviewer Concerns

CIRCULAR-BIAS

Opus labels another LLM

D-06 uses Opus to label for Gemini under test. Different family + IFCT-deterministic macros + every-label verification mitigate. RD audit = V1.5 trigger.

TIMELINE

First-time RN shipper drift

14-week target may stretch 18–20. Mitigation: Expo managed workflow, Hello-World Week 1, EAS configured Week 1, 5–10d buffer.

VENDOR

Provider free-tier rate limits

Gemini 10 RPM caps ~50 lunch-concurrent. Mitigation: 429-fallback chain, OpenRouter fallback drill 24h, per-call provider tag.

MOAT

Advice "on the side" temptation

Doc corrected to inline-on-every-card. If P3 UI ever buries advice in coach tab, moat collapses. Locked Invariant in Card Demo.

DEMAND

No verbatim ₹299 quote yet

Gate 0c closes this Week 1. Below 3 quotes → pricing thesis weakens → re-evaluate paid tier model before Phase 5.

VISION

Thali photo accuracy untested

Lit shows 49–76% error on multi-item dishes. Gate 0a thali bucket tests. Fail → "snap each item separately" UX V1.

V1.5

Two-persona temptation

"Target both" instinct re-surfaces. V1 locks one (youth muscle-gain). Weight-loss = V1.1 trigger-gated. Housewife = V2 separate brand.

V2

Cal AI competitive durability

Cal AI can ship Indian context with prompt update. Real durable moat = dataset (post-PMF) + brand. 6–12mo head-start realistic, not "forever."
