# NAME-V2: Sound-Catchy Brainstorm

**Brief.** Founder rejected V1 finalists (Niwala / Khurak / Saath) on the grounds that they don't *land* when spoken aloud. V2 re-runs the brainstorm with a single overriding constraint: **sound-catchiness when said out loud.** Reads, scans, hashtags, voice notes — all need to "stick" after one hearing. Reference patterns: Cred, Cult, Slice (1 syl, hard ending), Nykaa, Swiggy (2 syl, vowel ending), Ola (2 syl, vowel ending), Paytm (1 syl, hard ending). Mascot is a Langur named **Bali**, so the name must either pair with "Bali" naturally or stand cleanly alone.

**Hard rules.** ≤ 2 syllables. No tongue-twisters. No silent letters ("kh" out — kills Khurak). No soft endings (M / N / NG fade in noise). Vowel ending preferred. Distinctive consonant cluster (K, T, J, Z, V). Reads = spoken. No religious/political baggage. No collision with existing well-known brand.

---

## Candidate Pool (30 names, themed)

Each candidate scored on 5 axes (1–5 scale, higher is better unless noted):

- **Sound (S)** — how it lands aloud, 5 = sticks immediately
- **Syl (Y)** — syllables (1 = 1 syl, 2 = 2 syl, 3 = 3+ syl). Lower is better; we invert into a +score = (4 − Y), so 1 syl = 3, 2 syl = 2, 3 syl = 1
- **Vow (V)** — vowel ending? 1 = yes, 0 = no
- **Mem (M)** — memorability after one hearing, 5 = unforgettable
- **Pro (P)** — pronounceability for non-Hindi reader, 5 = anyone gets it first try

Composite = S + (4 − Y) + V + M + P (max 19).

## Final note on sound

The pattern that's emerging across the Indian startup canon (Cred, Cult, Slice, Nykaa, Swiggy, Ola, Zomato, Zerodha, Razorpay):

- **Hard consonant front + open vowel back** (Nykaa = N+yKAA, Swiggy = SW+iggee, Zomato = Z+omato, Tejo = T+jo).
- **Either 1 syllable + hard ending** (Cred, Cult, Slice, Zor, Ghee) **or 2 syllables + vowel ending** (Nykaa, Swiggy, Ola, Tejo, Sahi, Jora, Veera).
- **3+ syllables** survive only with extreme rhythmic regularity (Zo-ma-to, Ra-zor-pay) — Niwala (3 syl, no front consonant punch) flunked the test, which is the right call.

V1 finalists violated the pattern. V2 finalists obey it. Founder should record themselves saying each top-5 name 10 times into a voice memo, then play it back next morning cold — the one that re-enters the brain unprompted is the answer.
